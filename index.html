About the role

Our client, a growing technology company in Dallas, is looking for an experienced Software Developer to design, build and maintain scalable web applications and services. You'll work with product managers, designers and other engineers to ship reliable features end to end.

Responsibilities

  • Design, develop, test and deploy back-end services and RESTful APIs.
  • Build responsive, accessible front-end features using modern JavaScript frameworks.
  • Write clean, maintainable, well-tested code and take part in code reviews.
  • Work with relational databases: data modeling, query writing and performance tuning.
  • Troubleshoot production issues and improve system reliability and performance.
  • Collaborate in an Agile/Scrum team and contribute to technical design discussions.

Requirements

  • 5+ years of professional software development experience.
  • Strong proficiency in Java (Spring Boot) or a similar back-end language.
  • Hands-on experience with JavaScript/TypeScript and React.
  • Solid understanding of SQL and relational database design.
  • Experience with cloud platforms (AWS preferred), Docker and CI/CD pipelines.
  • Familiarity with Git, unit testing and Agile methodologies.
  • Bachelor's degree in Computer Science or a related field, or equivalent experience.

Nice to have

  • Experience with microservices and message queues (Kafka / RabbitMQ).
  • Exposure to Kubernetes and infrastructure-as-code (Terraform).
